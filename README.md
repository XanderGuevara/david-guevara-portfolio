# Portafolio Profesional — Ing. David Guevara

Portafolio oficial del **Ing. David Guevara** (**Ingeniero en Sistemas**, Preespecialización en **Cloud Computing** y Certificado por **Academia Kodigo** como **Web Developer Jr.**).

## Arquitectura & Firma Técnica
- **Framework:** Astro 5 (`Zero-JS` por defecto, 100/100 Lighthouse).
- **Firma Estructural:** **HTML5 100% Semántico Puro** (**0 etiquetas `<div>`** en todo el árbol DOM).
- **Motor Parallax Híbrido 60fps:** CSS Scroll-Driven Animations + Red Cuántica en `<canvas>` con inercia de scroll y micro-inclinación 3D acelerada por GPU.
- **Paleta & Tipografía:** Dark Tech (`#0a0a0f`) con acentos Esmeralda (`#10b981`) y Cian (`#06b6d4`), tipografía **Space Grotesk + Plus Jakarta Sans + JetBrains Mono**.

## Comandos

```bash
npm install
npm run dev
npm run build
```
