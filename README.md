# Portafolio web — David Alexander Guevara

Portafolio personal desarrollado con **Astro** para presentar proyectos, experiencia y medios de contacto.

## Perfil

Profesional formado en Ingeniería en Sistemas y Redes Informáticas, con experiencia en facturación y atención mayorista, soporte técnico informático y proyectos de desarrollo web.

**Competencias principales:** HTML5 semántico, organización de proyectos Astro, Git y GitHub. Conocimientos básicos funcionales de JavaScript y trabajo con CSS apoyado por herramientas de inteligencia artificial.

## Secciones del sitio

La página principal (`src/pages/index.astro`) utiliza componentes independientes:

- `Navbar`: navegación.
- `Hero`: presentación.
- `Projects`: proyectos.
- `SignatureArchitecture`: presentación de decisiones de diseño.
- `Experience`: experiencia.
- `Contact`: contacto.
- `Footer`: cierre del sitio.

## Tecnologías

- Astro 5.
- HTML5, CSS y JavaScript.
- Git y GitHub para control de versiones.

El proyecto contiene elementos visuales y efectos de interacción. No se declaran puntuaciones Lighthouse ni tasas de fotogramas sin mediciones reproducibles.

## Desarrollo local

```bash
git clone https://github.com/XanderGuevara/david-guevara-portfolio.git
cd david-guevara-portfolio
npm install
npm run dev
```

Para generar y previsualizar la compilación:

```bash
npm run build
npm run preview
```
